# Red Earth Plumbing

Professional website for Red Earth Plumbing — a Batemans Bay plumbing and gas fitting business.

Built with Next.js, TypeScript, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
